# Projet Universitaire: Implémentation du Jeu Othello sur un Thor

## Description du Projet
Ce projet vise à implémenter la logique du jeu Othello en utilisant le langage de programmation Python. Le jeu sera joué sur un thor, une version modifiée du plateau de jeu traditionnel.

## Règles du Jeu Othello
Othello est un jeu de stratégie pour deux joueurs, joué sur un plateau de 8x8 cases. 
Les joueurs prennent chacun un côté (noir ou blanc) et placent alternativement des pions de leur couleur sur le plateau. 
Le but du jeu est de capturer les pions de l'adversaire en les encerclant avec ses propres pions. 
Le joueur avec le plus de pions de sa couleur à la fin du jeu gagne.

## Qu'est-ce qu'un Thor?
Un thor est une version modifiée du plateau de jeu où les bords du plateau sont connectés. 
Cela signifie que si un pion sort d'un côté du plateau, il réapparaît de l'autre côté. Cela ajoute une dimension supplémentaire de stratégie au jeu.
